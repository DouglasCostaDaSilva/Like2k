API do Zyropay

Crie cobranças PIX, consulte pagamentos e receba avisos no seu sistema. A API usa JSON, valores sempre em centavos (R$ 149,90 = 14990) e datas em ISO 8601.

Base URL: https://seu-dominio

Taxa: 2% por PIX pago, com mínimo de R$ 0,30, já descontada em net_amount. Cobranças que expiram ou são canceladas não pagam taxa.

Autenticação

Gere sua chave em Painel › Integração e envie em todas as requisições:

Authorization: Bearer zp_live_xxxxxxxxxxxxxxxx

Limite de 120 requisições por minuto por conta. Nunca exponha a chave no navegador ou em apps: chame a API pelo seu servidor.

Criar cobrança

POST/v1/charges
CampoTipoDescrição
amount *inteiroValor em centavos, de 100 (R$ 1,00) a 5.000.000 (R$ 50.000,00).
descriptiontextoAparece no checkout e no app do banco. Até 140 caracteres.
external_idtextoSeu ID do pedido. Pode ser usado para consultar a cobrança.
expires_ininteiroValidade em segundos, de 300 a 86400. Padrão: 1800 (30 min).
payerobjetoname, email e document (CPF/CNPJ), todos opcionais.

Mande o header Idempotency-Key com um valor único por pedido: se a mesma requisição chegar duas vezes, a API devolve a mesma cobrança em vez de criar outra.

curl -X POST /v1/charges \
  -H "Authorization: Bearer zp_live_..." \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: pedido-4821" \
  -d '{
    "amount": 14990,
    "description": "Pedido #4821",
    "external_id": "4821",
    "payer": { "name": "Maria Souza", "email": "maria@email.com" }
  }'

Consultar cobrança

GET/v1/charges/{id ou external_id}

Retorna a cobrança no mesmo formato acima, com o status atualizado.

Listar cobranças

GET/v1/charges?limit=20&status=paid

limit de 1 a 100 (padrão 20). status opcional. Resposta: { "data": [ ...cobranças ] }, das mais novas para as mais antigas.

Cancelar cobrança

POST/v1/charges/{id}/cancel

Só funciona para cobranças pending. O QR Code para de aceitar pagamentos.

Webhooks

Cadastre a URL em Painel › Integração. Enviamos um POST em JSON a cada evento:

  • charge.created, charge.paid, charge.expired, charge.canceled, charge.refunded: data é a cobrança.
  • withdrawal.requested, withdrawal.paid, withdrawal.rejected: data é o saque.
{
  "id": "evt_3b1f8c2a9d",
  "type": "charge.paid",
  "created_at": "2026-10-01T15:02:11.000Z",
  "data": { "id": "ch_9f2c41e0a7b3d5e6f810", "status": "paid", "amount": 14990, ... }
}

Responda com qualquer status 2xx em até 10 segundos. Se não responder, reenviamos depois de 10 s, 1 min, 5 min, 30 min e 2 h. O mesmo evento pode chegar mais de uma vez: use o id do evento para ignorar repetidos.

Libere o pedido apenas no charge.paid. Se quiser, confirme consultando GET /v1/charges/{id}.

Validar a assinatura

Todo aviso tem o header Zyropay-Signature: t=1727794931,v1=5f2a…. Calcule o HMAC-SHA256 de "{t}.{corpo bruto}" com o segredo do webhook e compare com v1. Recuse avisos com t mais antigo que 5 minutos.

// Node.js
import crypto from 'node:crypto';

function avisoValido(rawBody, header, segredo) {
  const { t, v1 } = Object.fromEntries(header.split(',').map((p) => p.split('=')));
  if (Math.abs(Date.now() / 1000 - Number(t)) > 300) return false;
  const esperado = crypto.createHmac('sha256', segredo).update(`${t}.${rawBody}`).digest('hex');
  return crypto.timingSafeEqual(Buffer.from(esperado), Buffer.from(v1));
}
# PHP
[$t, $v1] = array_map(fn($p) => explode('=', $p)[1], explode(',', $_SERVER['HTTP_ZYROPAY_SIGNATURE']));
$esperado = hash_hmac('sha256', $t . '.' . file_get_contents('php://input'), $segredo);
$valido = hash_equals($esperado, $v1) && abs(time() - (int)$t) <= 300;

Status da cobrança

StatusSignificado
pendingAguardando o pagamento.
paidPago. O valor líquido já está no seu saldo.
expiredO prazo acabou sem pagamento.
canceledCancelada por você antes do pagamento.
refundedPagamento devolvido ao pagador.
failedO provedor recusou a transação.

Erros

Todo erro responde { "error": "mensagem em português" }.

HTTPQuando
400Parâmetro inválido (valor fora do limite, CPF inválido, etc.).
401Chave ausente ou inválida.
403Conta bloqueada.
404Cobrança não encontrada.
429Mais de 120 requisições por minuto.
502O provedor PIX não respondeu. Tente de novo (com a mesma Idempotency-Key).
